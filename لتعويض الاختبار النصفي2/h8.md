# تمرين تطبيقي: نظام إدارة الموظفين (الجزء الثاني - الإدارة والبيانات)

## 1. تطوير فئات الموظفين (المدراء والمستحقات)

يركز هذا الجزء على فئة "المدير" وكيفية التعامل مع البدلات الإضافية وحساب عدد الفريق.

### (أ) فئة المدير (Manager)

PHP

```
class Manager extends Employee {
    private $bonus;
    private $teamSize;

    public function __construct($id, $name, $department, $baseSalary, $bonus, $teamSize) {
        parent::__construct($id, $name, $department, $baseSalary);
        $this->bonus = $bonus;
        $this->teamSize = $teamSize;
    }

    public function calculateNetSalary() {
        // راتب المدير = الراتب الأساسي + البونص (بدون خصم تأمينات في هذا المثال)
        return $this->baseSalary + $this->bonus;
    }

    public function getEmployeeType() {
        return "مدير قسم";
    }
}
```

## 2. كشف الرواتب الإجمالي (Payroll Processing)

دالة برمجية تقوم بمعالجة مصفوفة من كائنات الموظفين المختلفة وحساب التكاليف الإجمالية.

PHP

```
function processTotalPayroll(array $employees) {
    $totalAmount = 0;
    foreach ($employees as $emp) {
        $net = $emp->calculateNetSalary();
        $totalAmount += $net;
        
        echo "الموظف: " . $emp->getName();
        echo " | الصافي: " . $net . " ريال <br>";
    }
    echo "<strong>إجمالي الرواتب الصافية: " . $totalAmount . " ريال </strong>";
}
```

## 3. هيكل قاعدة البيانات المتقدم (MySQL)

يتضمن هذا الجزء جداول إضافية لإدارة البدلات والمزايا الخاصة بالمدراء.

### (أ) جدول مزايا المدراء (Manager Benefits)

SQL

```
CREATE TABLE manager_benefits (
    id INT PRIMARY KEY AUTO_INCREMENT,
    manager_id INT,
    benefit_type VARCHAR(50), -- مثل: بدل سكن، سيارة، هاتف
    amount DECIMAL(10,2),
    start_date DATE,
    end_date DATE,
    FOREIGN KEY (manager_id) REFERENCES employees(id)
);
```

### (ب) استعلام تقرير الرواتب الشهري

SQL

```
SELECT 
    e.name, 
    e.employee_type, 
    s.month, 
    s.net_salary 
FROM employees e
JOIN salaries s ON e.id = s.employee_id
WHERE s.status = 'paid'
ORDER BY s.month DESC;
```

## 4. ملخص فني للمفاهيم المطبقة (Summary)

- **الوراثة (Inheritance):** استخدام `parent::__construct` لتمرير البيانات للفئة الأساسية.
    
- **تعدد الأشكال (Polymorphism):** معالجة أنواع مختلفة من الموظفين في مصفوفة واحدة واستدعاء نفس الدالة `calculateNetSalary`.
    
- **العلاقات (Relationships):** ربط جداول الموظفين بالرواتب والمزايا باستخدام `Foreign Keys`.
