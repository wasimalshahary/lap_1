# تمرين تطبيقي: ثغرات حقن الأوامر وتضمين الملفات

## 1. ثغرة حقن أوامر النظام (Command Injection)

تحدث هذه الثغرة عندما يقوم التطبيق بتمرير مدخلات المستخدم مباشرة إلى وظائف تنفذ أوامر على مستوى نظام التشغيل (مثل `exec` أو `shell_exec`). 1

### مثال على كود مصاب (أداة Ping):

PHP

````
if (isset($_POST['ip'])) {
    $target = $_POST['ip'];
    // خطأ: دمج مدخلات المستخدم مباشرة مع أمر النظام
    $cmd = "ping -c 4 " . $target;
    $result = shell_exec($cmd);
    echo "<pre>{$result}</pre>";
}
``` [cite: 3, 5, 8, 9]

### السيناريو الهجومي:
يمكن للمهاجم استخدام معاملات الفصل (مثل `;` أو `&&`) لتنفيذ أوامر إضافية. [cite: 20, 21]
* **المدخل الضار:** `8.8.8.8 ; cat /etc/passwd` [cite: 23]
* **الأمر الذي سيُنفذ:** سيقوم النظام بتنفيذ "Ping" ثم عرض ملف كلمات المرور الخاص بالنظام. [cite: 23]

## 2. طرق الحماية من حقن الأوامر

### (أ) استخدام `escapeshellarg()`
تقوم هذه الدالة بتغليف المدخلات بعلامات اقتباس ومعالجة الرموز الخطرة. [cite: 44, 49]

```php
$target = $_POST['ip'];
// الحماية بتغليف المتغير برمجياً
$safe_target = escapeshellarg($target);
$result = shell_exec("ping -c 4 " . $safe_target);
``` [cite: 47, 49]

### (ب) التحقق باستخدام القائمة البيضاء (Validation)
التأكد من أن المدخلات تتبع تنسيقاً محدداً (مثل عنوان IP). [cite: 43]

```php
if (filter_var($target, FILTER_VALIDATE_IP)) {
    // تنفيذ الأمر فقط إذا كان العنوان صالحاً
    $result = shell_exec("ping -c 4 " . $target);
}
``` [cite: 183, 186]

## 3. ثغرة تضمين الملفات (File Inclusion)
تسمح هذه الثغرة للمهاجم بتضمين ملفات من الخادم (LFI) أو من خادم خارجي (RFI). [cite: 92, 93]

### مثال على تضمين ملفات محلي (LFI):
```php
// كود مصاب يمرر اسم الملف عبر الرابط
$page = $_GET['page'];
include($page . ".php"); 
``` [cite: 96, 117, 118]

**الهجوم:** `index.php?page=../../../../etc/passwd%00` (محاولة الوصول لملفات النظام الحساسة). [cite: 133, 138, 139]

## 4. المقارنة الأمنية والحلول الجذرية



| نوع الثغرة | المخاطر | الحل المقترح |
| :--- | :--- | :--- |
| **Command Injection** | السيطرة الكاملة على السيرفر | تجنب وظائف النظام أو استخدام `escapeshellarg` [cite: 44, 49, 254] |
| **LFI / RFI** | تسريب بيانات أو تنفيذ كود خارجي | استخدام "قائمة بيضاء" لأسماء الملفات المسموحة [cite: 253, 258] |

### الحل الآمن لتضمين الصفحات:
```php
$allowed_pages = ['home', 'about', 'contact'];
$page = $_GET['page'];

if (in_array($page, $allowed_pages)) {
    include($page . ".php");
} else {
    include("404.php");
}
``` [cite: 173, 218, 219, 221, 222]

## 5. أفضل الممارسات الأمنية (ملخص الملف)
* **لا تثق أبداً بمدخلات المستخدم:** يجب فحص كل ما يأتي من `$_POST` أو `$_GET`. [cite: 115, 116, 257]
* **مبدأ الصلاحيات الأقل:** تشغيل الويب سيرفر بصلاحيات محدودة يقلل أثر حقن الأوامر. [cite: 102, 107, 108]
* **تعطيل الوظائف الخطرة:** في ملف `php.ini` عبر `disable_functions`. [cite: 89, 90]
