# تمرين تطبيقي: نظام إدارة الموظفين (OOP & Databases)

## 1. هيكل الفئات باستخدام الوراثة (Inheritance)

تم تصميم النظام باستخدام فئة أساسية مجردة (Abstract Class) تشتق منها أنواع الموظفين المختلفة لضمان تنظيم الكود وإعادة استخدامه.

### (أ) الفئة الأساسية (Employee)

PHP

```
abstract class Employee {
    protected $id;
    protected $name;
    protected $department;
    protected $baseSalary;

    public function __construct($id, $name, $department, $baseSalary) {
        $this->id = $id;
        $this->name = $name;
        $this->department = $department;
        $this->baseSalary = $baseSalary;
    }

    // دوال مجردة يجب تنفيذها في الفئات الابنة
    abstract public function calculateNetSalary();
    abstract public function getEmployeeType();
}
```

### (ب) فئة الموظف الدائم (Permanent Employee)

تتضمن حسابات التأمينات والخصومات الخاصة بالموظفين المثبتين.

PHP

```
class PermanentEmployee extends Employee {
    private $insurance = 0.14; // 14% تأمينات

    public function calculateNetSalary() {
        $deductions = $this->baseSalary * $this->insurance;
        return $this->baseSalary - $deductions;
    }

    public function getEmployeeType() {
        return "موظف دائم";
    }
}
```

## 2. إدارة الرواتب وكشوفات الحساب

يتضمن النظام دوال لحساب إجمالي الرواتب لجميع أنواع الموظفين (دائم، عقد، مدير) وعرض تفاصيلها.

**مثال على معالجة البيانات:**

PHP

```
foreach ($employees as $emp) {
    echo "الاسم: " . $emp->getName() . " | النوع: " . $emp->getEmployeeType();
    echo " | صافي الراتب: " . $emp->calculateNetSalary() . " ريال<br>";
}
```

## 3. تصميم قاعدة البيانات (MySQL)

يحتوي الملف على هيكل الجداول اللازمة لتخزين بيانات الموظفين والرواتب والعمليات المالية.

### (أ) جدول الموظفين (Employees)

SQL

```
CREATE TABLE employees (
    id INT PRIMARY KEY AUTO_INCREMENT,
    employee_type ENUM('permanent', 'contract', 'manager'),
    name VARCHAR(100) NOT NULL,
    department VARCHAR(50),
    base_salary DECIMAL(10,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### (ب) جدول الرواتب (Salaries)

يرتبط بجدول الموظفين لتسجيل الحركات المالية الشهرية.

SQL

```
CREATE TABLE salaries (
    id INT PRIMARY KEY AUTO_INCREMENT,
    employee_id INT,
    month YEAR_MONTH,
    net_salary DECIMAL(10,2),
    status ENUM('pending', 'paid', 'cancelled'),
    FOREIGN KEY (employee_id) REFERENCES employees(id)
);
```

## 4. المفاهيم البرمجية المطبقة

- **Encapsulation (التغليف):** استخدام خصائص `protected` و `private` لحماية البيانات.
    
- **Abstraction (التجريد):** استخدام `abstract class` لتعريف نموذج عام للموظف.
    
- **Polymorphism (تعدد الأشكال):** استدعاء دالة `calculateNetSalary()` التي تعمل بشكل مختلف بناءً على نوع الموظف.

## 5. ملخص العمليات

1. **تعريف الموظفين:** إدخال البيانات وتحديد نوع العقد.
    
2. **حساب المستحقات:** تطبيق المعادلات البرمجية بناءً على نوع الموظف (خصم ضرائب أو تأمينات).
    
3. **التخزين:** حفظ النتائج في قاعدة البيانات لضمان دقة السجلات المالية.
