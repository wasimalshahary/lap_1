
تمرين تطبيقي (تمهيدي) - تحليل أمني لتسجيل الدخول
المخاطر الأمنية المحتملة والحلول المقترحة
1. حقن SQL (SQL Injection)
الخطر: إدخال أوامر SQL ضارة عبر حقول الإدخال

الحل المبدئي: استخدام Prepared Statements مع معلمات

المرحلة: Code (التنفيذ)

php
// ❌ خطأ
$query = "SELECT * FROM users WHERE username = '$username' AND password = '$password'";

// ✅ صحيح
$stmt = $conn->prepare("SELECT * FROM users WHERE username = ? AND password = ?");
$stmt->bind_param("ss", $username, $password);
2. التخزين غير الآمن لكلمات المرور
الخطر: تخزين كلمات المرور كنص صريح (Plain Text)

الحل المبدئي: استخدام التجزئة القوية (Hashing) مثل bcrypt

المرحلة: Design & Code (التصميم والتنفيذ)

php
// ❌ خطأ
$hashed_password = md5($password);

// ✅ صحيح
$hashed_password = password_hash($password, PASSWORD_BCRYPT);
3. هجمات القوة الغاشمة (Brute Force)
الخطر: محاولات متكررة لتخمين كلمات المرور

الحل المبدئي: تحديد عدد المحاولات وإضافة تأخير زمني

المرحلة: Design & Code (التصميم والتنفيذ)

php
// تسجيل المحاولات الفاشلة
if ($login_failed) {
    $_SESSION['failed_attempts'] = ($_SESSION['failed_attempts'] ?? 0) + 1;
    if ($_SESSION['failed_attempts'] > 5) {
        sleep(5); // تأخير 5 ثواني
    }
}
4. التسريب المعلوماتي (Information Disclosure)
الخطر: كشف أسباب فشل التسجيل بدقة

الحل المبدئي: استخدام رسائل أخطاء عامة

المرحلة: Design & Code (التصميم والتنفيذ)

php
// ❌ خطأ - يكشف معلومات النظام
if (!user_exists($username)) {
    echo "اسم المستخدم غير موجود";
} elseif (!password_verify($password, $hashed_password)) {
    echo "كلمة المرور غير صحيحة";
}

// ✅ صحيح - رسالة عامة
echo "اسم المستخدم أو كلمة المرور غير صحيحة";
5. هجمات CSRF (Cross-Site Request Forgery)
الخطر: تنفيذ طلبات غير مصرح بها باسم المستخدم

الحل المبدئي: استخدام رموز CSRF Tokens

المرحلة: Design & Code (التصميم والتنفيذ)

php
// إنشاء Token عند تحميل الصفحة
$_SESSION['csrf_token'] = bin2hex(random_bytes(32));

// في النموذج
<input type="hidden" name="csrf_token" value="<?php echo $_SESSION['csrf_token']; ?>">

// التحقق عند الاستقبال
if ($_POST['csrf_token'] !== $_SESSION['csrf_token']) {
    die("طلب غير مصرح به");
}

توصيات إضافية:
المرحلة Design: وضع السياسات الأمنية وهيكلة النظام

المرحلة Code: تنفيذ الحماية في الكود المصدري

المرحلة Test: اختبار الاختراق والمراجعة الأمنية
